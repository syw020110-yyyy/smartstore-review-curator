# 🛍️ Smartstore Review Curator & Insight Extractor

네이버 스마트스토어 상품 리뷰를 수집하고, 상세페이지 개선에 즉시 활용할 수 있는 **'고품질 포토리뷰(100자 이상)'** 필터링 및 **'반복 만족 포인트 요약 인사이트'**를 도출하는 대시보드 도구입니다.

---

## 📌 주요 기능
1. **간편하고 안정적인 데이터 수집 모드**:
   - **엑셀(.xlsx) / CSV 파일 업로드 (추천)**: 크롬 확장 프로그램(리뷰하운드, 리뷰 수집기 등)에서 대량(수천~1만 건) 추출한 엑셀/CSV 파일을 그대로 업로드
   - **리뷰 텍스트 직접 붙여넣기**: 브라우저에서 복사한 리뷰 텍스트를 바로 붙여넣어 1초 만에 분석
   - **데모 샘플 데이터**: 파일이나 API 키 없이도 즉시 기능 체험 가능
2. **결정적 필터링 (Deterministic Filter)**:
   - 최소 글자 수 슬라이더 (기본 100자)
   - 포토 첨부 필수 체크박스 (`image_count >= 1`)
   - 단답형("좋아요", "빠릅니다") 리뷰 배제 및 고관여 리뷰 선별
3. **Google Gemini AI 인사이트 추출**:
   - `gemini-2.5-flash` / `gemini-2.5-pro` 기반 Structured Output
   - 빈출 만족 테마 Top 3~5 추출 및 만족 비중(%) 추정
   - 상세페이지 상단에 바로 복사해 넣을 수 있는 **추천 헤드카피** 제안
   - 고객의 생생한 표현 그대로의 **대표 원본 인용구 (VOC)** 매핑
   - 상세페이지 기획자를 위한 **실천 액션 플랜 3가지** 도출
4. **결과 다운로드 & 내보내기**:
   - 큐레이션된 고품질 리뷰: **CSV 다운로드**, **Excel(.xlsx) 다운로드**
   - AI 인사이트 분석 결과: **마크다운 보고서(.md)**, **구조화 데이터(.json)** 내보내기

---

## 🚀 실행 방법

### 1. 패키지 설치
```bash
pip install -r requirements.txt
playwright install
```

### 2. Streamlit 대시보드 실행
```bash
streamlit run app.py
```
실행 후 웹 브라우저에서 `http://localhost:8501`로 자동 접속됩니다.

### 3. Google Gemini API 키 설정 (선택사항)
- 대시보드 사이드바의 **"Gemini API Key"** 입력창에 직접 입력하거나,
- `.env` 파일에 `GEMINI_API_KEY=your_key` 형태로 저장해둘 수 있습니다.
- API 키가 없어도 **"🧪 API 키 없이 데모 인사이트 체험하기"** 버튼을 통해 즉시 분석 결과를 체험할 수 있습니다.
